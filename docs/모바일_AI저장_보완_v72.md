# 모바일 PWA 및 요청 AI 저장 보완 — v72

상태: 로컬 구현·검증 완료. 이 문서 작성 시 운영은 v71이며, 새 커밋·푸시·배포는 하지 않았다.

## 모바일 배치

- 관리자 제목을 공통 헤더 높이 안에서 세로 중앙 정렬.
- 필터 이동 화살표를 칩 바깥의 별도 터치 영역에 배치. 이동 불가 버튼은 숨김·비활성 처리하고 크기 변경 시 다시 계산.
- 최근 견적은 모바일에서 고객 정보와 금액을 분리하여 고객명·날짜 잘림 감소.
- 수량 감소·숫자 입력·증가 버튼 간격 확보, 숫자 입력 배경 구분.
- 첫 단계에서 사용하지 않는 뒤로가기 자리까지 단계 표시 영역 확장.
- 요청 상태 버튼은 좁은 화면에서 줄바꿈, AI 견적 생성 버튼도 문구 줄바꿈 허용.
- 관리자 페이지에 viewport-fit=cover 적용. 상단 안전 영역, 하단 메뉴 높이·고정 버튼·본문 여백에 safe-area-inset 반영.
- 빈 알림 아이콘 자리 제거, 작은 화면 업데이트 안내 줄바꿈.

## 요청별 AI 결과 저장

- 기존에는 DOM의 임시 HTML만 남아 새로고침·재접속 시 사라졌다.
- 서버에서 요청 입력 내용을 식별하는 키를 만들고, 해당 요청의 실제 서버 데이터로 분석한다.
- 성공한 결과만 견적요청 시트의 `AI분석JSON` 열에 저장한다. 열이 없으면 기존 열 뒤에 추가하며 기존 셀은 덮어쓰지 않는다.
- 관리자 요청 조회에 분석 결과·저장 시각 포함. 연결된 견적이 있어도 저장 결과 표시.
- 다시 분석은 확인 후 진행. 실패하면 이전 결과 유지. 같은 요청의 연속 클릭 차단.
- Gemini 호출 중 다른 행 삭제로 행 번호가 바뀌어도 요청을 다시 찾는다. 대상 삭제·내용 변경·중복 식별은 저장 중단.
- 결과는 요청의 최신 분석 한 건이다. 과거 분석 버전별 이력 기능은 포함하지 않는다.
- 이전 버전에서 이미 사라진 분석은 복구하지 못한다. 새 서버·웹 배포 후 분석한 내용부터 저장된다.

## 검증

- 추가 요청: 공통 Gemini 호출을 `gemini-3-flash-preview`에서 `gemini-3.7-flash`로 변경. 요청 메모·사진 분석 및 연결 테스트에 함께 적용된다. 공식 모델 문서 https://ai.google.dev/gemini-api/docs/models/gemini-3.7-flash 에서 ID 및 텍스트/이미지 입력·구조화 출력 지원을 확인했다. 실제 계정 호출은 배포 후 확인해야 한다.

- 전체 15개 mjs 테스트 파일 통과. 저장·복원·행 이동·대상 삭제/수정·실패 보존·잘못된 JSON·추가 열 보존·익명 차단 포함.
- verify-reskin 및 배포 패키지 검증 통과. 계산 모듈과 A4 출력 함수는 변경하지 않았다.
- 점검용 브라우저에서 11개 관리자 페이지를 320px/390px로 확인. 요청 페이지의 작은 화면 넘침은 상태 버튼 줄바꿈으로 수정 후 재측정.
- 가상 API로 분석 → 페이지 재접속 → 결과 복원 → 재분석 실패 시 이전 결과 유지 흐름 확인.
- 실제 Gemini·운영 시트 저장은 아직 실행하지 않았다. iOS/Android 설치 PWA의 실제 안전 영역은 배포 후 휴대폰 확인이 필요하다.

## 배포 시

사용자 커밋·배포 승인 후 현재 서버 소스를 별도 백업하고 GAS를 먼저 갱신한다. 기존 PIN 초기화는 다시 실행하지 않는다. 서버 정상 확인 후 웹 v72를 배포하고, 관리자 요청 한 건 분석 및 재접속 복원을 확인한다.
