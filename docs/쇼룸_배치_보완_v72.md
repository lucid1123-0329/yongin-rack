## 배치도

- 매장 크기 5~200평. 숫자 입력, 슬라이더, 빠른 선택을 같은 상태로 동기화.
- 12개 상담용 업종 프로필. 사진 속 기존 현장을 재현하는 기능은 아니다.
- 평수를 면적으로 환산한 직사각형에 벽면·중앙 랙을 실제 길이 비율로 배치한다.
- 중앙·전면 통로, 큰 공간의 횡단 통로를 먼저 비운다. 선반 간 겹침과 경계 침범을 검사한다.
- 도면 블록 하나가 1대이며 수량 목록·도면·문의 문구가 동일한 모델을 사용한다.
- 랙 치수·통로 폭·공간 비율은 공개된 계산 가정이다. 실측 견적, 안전·피난 기준 충족, 지게차 운행 가능성을 보증하지 않는다. 기둥·여러 출입구·계산대·상담 공간 등은 미반영이다.
- 쇼룸 사진은 잘리지 않게 표시하고 설명 점을 실제 표시된 이미지 영역 기준으로 계산한다. 설명 박스는 사진 아래로 분리했다.
