# 용인랙 디자인 시스템 v3 — 한국형 트렌디 앱 스타일 (2026-09-16)

목표: 토스·당근·카카오페이 같은 국내 생활 금융/커머스 앱에서 익숙한 문법. "문서 같은 직각"이 아니라 "흰 카드가 회색 바탕 위에 떠 있는" 구조, 테두리 대신 배경 대비, 큰 숫자, 한 가지 브랜드색, 부드러운 모서리. 60대 사용자 기준 글자·터치 하한은 유지.

## 토큰
```css
:root{
  --bg:#F2F4F6;            /* 바탕 회색 */
  --surface:#FFFFFF;       /* 카드 */
  --fill:#F2F4F6;          /* 입력·비활성 칩 채움 */
  --fill-2:#E5E8EB;        /* 눌림·구분 */
  --line:#EEF0F2;          /* 카드 안 구분선(아주 연함) */
  --text:#191F28;          /* 본문 */
  --text-2:#4E5968;        /* 보조 */
  --text-3:#8B95A1;        /* 라벨·캡션 */
  --brand:#2F6BFF;         /* 브랜드 블루(주 버튼·선택·링크) */
  --brand-weak:#E8F0FF;    /* 선택 칩 배경, 안내 박스 */
  --accent:#FF6B00;        /* 알림 배지·강조 1곳 */
  --ok:#1FA36B; --ok-weak:#E6F7EF;
  --danger:#F04452; --danger-weak:#FEECEE;
  --r-card:20px; --r-ctl:14px; --r-chip:999px; --r-sheet:24px;
  --shadow-card:0 2px 12px rgba(25,31,40,.06);
  --s1:8px;--s2:12px;--s3:16px;--s4:20px;--s5:24px;--s6:32px;
}
```
- 서체: **Pretendard**(jsdelivr CDN, 이미 사용하던 것) 400/500/600/700. 숫자 tabular.
- 타이포: 화면 제목 22/700, 섹션 제목 17/700, 본문 17/500, 보조 15/500(--text-2), 캡션 15/500(--text-3, 13px 금지: 60대 기준), 큰 금액 32/800(letter-spacing -0.02em), 카드 금액 19/700.
- 간격: 카드 패딩 20, 카드 사이 12, 섹션 사이 24, 화면 좌우 20.
- 모서리: 카드 20, 버튼·입력 14, 칩 999, 바텀시트 상단 24.
- 그림자: 카드 `--shadow-card` 1종만. 그 외 없음. 테두리는 원칙적으로 없음(선택 상태·포커스 제외).
