## 실제 변경

### 후속 추가: 이미지 저장·견적 요청 연결

이 아래의 초기 버전 설명 중 ‘문의 요약만 전달’은 다음 기능으로 대체했다.

- `배치 이미지 저장 (PNG)`: 편집 배치 상태로부터 Canvas로 생성한다. 평수·형태·외곽 치수·가구 번호·종류·점유 치수·좌표·상담용 주의 문구를 포함한다. AI 이미지나 화면 캡처가 아니며 선택 테두리·확대 상태에 영향을 받지 않는다.
- `이 배치로 견적 요청`: 동일 탭 세션에 검증된 배치 스냅샷을 저장하고 공개 요청 폼으로 이동한다. 선반 수량·업종 기반 랙 종류 후보·면적/형태를 입력하고 배치도 JPEG를 자동 첨부한다. 연락처 입력 및 실제 제출은 고객이 직접 한다.
- 기존 서버가 JPEG 첨부를 허용하므로 제출용은 JPEG, 다운로드용은 PNG다. 배치 이미지 1장을 포함해 총 5장 제한. 누락·만료(24시간)·저장 공간 오류·배치 오류를 안내한다. 배치 누락 상태에서는 명시적으로 배치 없이 진행을 선택하기 전 제출을 차단한다. 실패 시 재시도용 스냅샷은 유지하고 성공 후 해당 키만 삭제한다.
- 선반 높이·단수·하중·제조사 규격·가격은 추정 입력하지 않는다. 계산대·테이블·기둥·재고 구역은 선반 수량에서 제외한다. 관리자 정식 금액 견적서는 기존 요청 처리 흐름으로 작성하며, 공개 화면에서 자동 확정 발행하지 않는다.
- 브라우저 점검 스킬로 PNG 다운로드 요청, 공개 폼 이동·수량 입력·배치 이미지 표시를 확인했다. 실제 운영 요청을 제출하지 않았다. 회귀 테스트에서 메모·수량·그리기·저장 오류·누락/만료·사진 제한을 검사한다.

- 고객 요청에 따라 11개 업종 전체를 상품 진열·고객 또는 직원 이용 장면의 AI 연출 이미지로 교체했다. 각 이미지에 AI 표시, 설명, 대체 텍스트를 넣고 별도 블로그 시공 기록과 구분했다. 제조사 모델·하중 인증용 이미지가 아니다.
- 기존 이미지는 삭제하지 않았다. 선택한 업종 이미지만 내려받아 초기 11장 동시 로딩을 피한다.
- 5~200평, 가로형·세로형·정사각형·ㄱ자형. ㄱ자는 외곽 사각형의 1/4을 제외하고 입력 면적을 맞춘다.
- 선반·계산대·체험 테이블·재고 구역·기둥 추가, 클릭 선택, 드래그 또는 위치 찍기, 방향 버튼(25cm), 크기 변경, 회전, 복제·삭제, 50단계 되돌리기·다시 실행, 확대.
- 둘러보기·체험상담·재고작업·빈 공간 시작 구성. 최대 밀도 배치가 아닌 자유 편집의 출발점이다.
- 면적·형태 변경 시 가구를 삭제하지 않으며 충돌·경계 문제를 표시한다. 새 구성 적용도 되돌릴 수 있다.
- JSON 파일 저장·불러오기. 형식·면적·좌표·크기·중복 ID·겹침·입구·경계를 검사한다. 브라우저 자동 저장은 하지 않으므로 떠나기 전 파일 저장이 필요하다.
- 문의에는 요약만 전달되며 도면 파일은 상담 때 별도 전달해야 한다.
- 통로 폭, 피난, 적재 하중, 장비 회전, 실제 기둥·문 위치 등은 검증하지 않는 상담용 편집 도구다. 입구는 아래 중앙 고정이다.
