# 견적 작성 회귀 검수 — 2026-09-18

## 범위와 상태

v82 배포 후 신고된 부속품 단독 추가 모달 누락을 재현하고, 관련 담기 경로를 보완했다.
이번 변경은 v83 배포 대상이다. 배포 성공 여부는 GitHub Actions 실행 결과와 운영 파일 대조로 별도 확인한다.
운영 고객 데이터와 서버 설정은 변경하지 않았다.

## 수정 사항

- 부속품만 추가해도 추가 완료 모달을 표시한다. 부품 종류 선택 여부와 무관하게 작동한다.
- 최근 사용·자주 사용·고객 패턴에서 바로 담아도 후속 모달을 표시하고, 해당 종류로 더 담을 수 있다.
- 바로 담기는 저장된 과거 가격 대신 현재 로드된 단가표를 대조한다. 삭제·중복 식별·단가 미입력 품목은 재선택을 안내한다.
- 폭 필터 변경 시 이전 규격 선택을 해제한다.
- 부속품과 확정 단가 행의 0원·음수·비정상 단가를 차단한다.
- 추가 항목·추가 선반의 수량은 1~9999 정수로 검증한다. 선반 수량이 잘못되면 랙만 먼저 담기는 부분 추가도 차단한다.
- 마진 추가 직전에 현재 담은 품목을 기준으로 다시 계산한다. 할인·마진의 비정상 금액도 차단한다.
- 음성 일괄 담기는 기존처럼 최종 확인 단계로 이동하도록 유지한다.
- 공통 금액 계산과 견적서 출력 함수는 변경하지 않았다. D/C는 기존의 VAT 포함 총액 차감 방식을 유지한다.

## 재실행

`node tools/prepare-release.mjs`는 보호 규칙과 자동 테스트를 실행한다.
이번 조합 검증은 `test/estimate-selection-regression.test.mjs`에 포함된다.
Windows에서는 브라우저 기반 기존 검사 2개를 포함해 96개가 실행된다.
Linux 배포 환경에서는 Windows 전용 브라우저 검사 2개를 제외한 자동 검사를 실행한다.

## 검증 한계

- 로컬 브라우저는 합성 단가/고객 데이터를 사용하는 격리된 점검 환경이다.
- 실제 Google Sheets에 신규 견적을 저장하거나 실제 고객에게 전송하지 않았다.
- 실제 휴대폰의 키보드·PWA 수명주기·네트워크 장애는 직접 재현하지 않았다.
- 음성 API 실호출과 실제 녹음 정확도는 이번 점검 범위가 아니다. 기존 회귀 테스트만 재실행했다.
- 이 검수는 명시된 경로·입력 조합에 대한 확인이지, 모든 가능한 상태에서 무결함을 보증하는 것은 아니다.
