참고
- 하이퍼 진열대 DB의 깊이(380/400/450/540/600/800)는 편면 기준으로 보이고 카탈로그 중앙용 깊이(800~1600)는 양면 합산으로 보임. 확인 필요.
- 하이퍼 높이 975는 카탈로그 980과 동일 규격으로 간주.
- 신형 곤도라는 DB가 부품+세트(3종) 구조라 W×D×H 조합 비교가 직접 되지 않음.
- 파렛트랙은 카탈로그가 부품 단위(포스트 2.2T×85, 로드빔 2T×100/125/150, 연결빔, 브레싱, 포스트베이스)라 부품 조합형(모델 C) 등록이 적합.
