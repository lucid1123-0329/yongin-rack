# 용인랙 디자인 시스템 v2 — 최종 확정 (2라운드 반영)

## 2라운드 반영 사항
- 시그니처 장식 축소: **기둥·빔 폐지, 치수 인출선 폐지.** 시그니처는 **명판 표찰 1종**만. 품목 위계는 `01` `02` 번호(19/700)와 여백으로.
- 규격 표기: 일반 텍스트 `2,500 × 1,000 × 4,500 mm` (19/600, tnum) 한 줄 + 아래 줄 `2단 · 단당 1,000 kg · 독립 1 + 연결 3` (17/500 ink-2).
- 하단 바: 입력 시트(직접 고르기, 확인, 고객 문의)에서는 **탭바 숨김**, 64px 단일 액션 바만 고정. 탭바는 홈·업무함·관리·완료 화면에만.
- 텍스트 버튼 폐지: 모든 행동은 최소 48px 높이 외곽선 버튼. 전화번호는 전화 아이콘 + 밑줄.
- "전화 문의 등록": 업무함 상단(현황표 아래)에 전폭 64px 외곽선 버튼.
- 모바일 표: 현황 4칸은 2×2. 견적서 품목표는 `품목 / 수량 / 금액` 3열 + 규격 행 전체 폭. 문의 카드는 정보 1열 + 행동 2열.
- 모서리: 전부 0px(프레임·버튼·입력·체크·키패드). 토큰 --r-ctl 삭제.
- 흰색 토큰 명시: --surface #FCFBF9 가 유일한 "흰색". #FFF 사용 금지.
- 굵기 규칙 정정: "한 행에 굵은 요소 하나"는 텍스트 행에만 적용. 현황 2×2 숫자와 견적서 상단 명판은 예외.
- 선택 상태: 1.5px 잉크 테두리 + 우측 `선택됨` 17/700 표찰. 좌측 막대 폐지.

## 토큰
```css
:root{
  --canvas:#EFEEEA; --surface:#FCFBF9; --ink:#1B1F24; --ink-2:#4A5058; --rule:#C9C7C0;
  --accent:#D84E0B; --ok:#2E6B45; --danger:#B2382B; --disabled-bg:#E4E2DC; --disabled-ink:#6B7079;
  --s1:8px; --s2:12px; --s3:16px; --s4:24px; --s5:32px; --s6:40px;
}
```
- 서체: IBM Plex Sans KR 400/500/600/700 (Google Fonts link). 숫자 전부 `font-variant-numeric: tabular-nums lining-nums`.
- 타이포 T1 34/700 · T2 26/700 · T3 21/600 · T4 19/600 · T5 18/500 · T6 17/500. 700 초과 금지.
- 간격 8/12/16/24/32/40만. 그림자 없음. 모서리 0.
- 선: 1px --rule 일반, 1.5px --ink 블록 외곽·선택·주요 구분.
- 포커스 3px --accent offset 2px.

## 컴포넌트 상태(필수 구현)
- 버튼: 기본 / 눌림(배경 --canvas, 잉크 버튼은 #2A3038) / 비활성(배경 --disabled-bg, 글자 --disabled-ink, 테두리 없음, 탭 시 하단 안내 문구 3초) / 저장 중(라벨 "저장 중…" + 재탭 무시).
- 입력: 기본 1.5px --rule / 포커스 / 오류(2px --danger + 아래 16px --danger 문구, 위 간격 4px) / 단위 suffix 17px --ink-2 우측 내부 고정.
- 빈 상태: 200px 박스 중앙 "접수된 문의가 없습니다"(19/500) + 64px "전화 문의 등록" 버튼. 검색 결과 없음도 동일 양식.
- 계산: 품목 합 → 부대비용 합 → 마진율 적용 → 할인 차감(총액 초과 불가, 오류 표시) → 부가세 10% 반올림. 앞 단계 변경 시 뒤 선택은 유지(품목 종류 변경 시에만 규격 초기화).

## 화면
- 홈: 헤더 좌측 워드마크 `용인랙`(22/700, 자간 -0.04em), 우측 오늘 날짜 명판. 시작 버튼 3개 72px 외곽선, 좌측 `01/02/03`(19/600 ink-2) + 제목(19/600) + 설명(17/500). 자주 쓰는 세트는 세로 목록(행 1px 구분, 규격 텍스트 + 구성 + [이 세트로] 48px 버튼 우측).
- 직접 고르기: 단일 시트, ①종류 2열 격자(각 셀 96px, 1.5px 선, 선택 시 `선택됨`) → ②규격 목록(선택 후 노출, 각 64px) → ③수량(−/+ 64px, 자동 분할 문구). 하단 64px 액션 바: 좌 `담은 3대 · 2,468,400원` 우 [담기]. 탭바 숨김.
- 확인: 고객 블록 / 품목 블록(번호 01,02…) / 부대비용 토글 4행(직각 스위치 트랙 56×32) / 마진·할인 / 합계(총액 T1 우측, `원` 80%) / 주 CTA 64px 잉크. 탭바 숨김.
- 완료: 견적번호 명판 크게(26/700, 자간 .08em) + 총액 T1. [카카오톡으로 보내기] 64px accent 배경(유일한 accent 면). 보조 3개 외곽선 56px. 탭바 표시.
- 업무함: 현황 2×2 표(1.5px 외곽, 1px 격자, 숫자 26/700, 라벨 17) → [전화 문의 등록] 64px 외곽선 → 새 문의(카드: 이름 19/600, 전화 밑줄+아이콘, 규격 한 줄, 메모 2줄, 접수시각 17 ink-2, 상태 명판; 행동 2열 [전화하기 외곽선][견적 작성 잉크]; [내 폰으로 주소 보내기] 48px 외곽선 전폭) → 연락할 곳 → 최근 견적(행 64px, 이름·상태 명판·날짜·금액 우측 tnum).
- 관리: 64px 행, 1px 구분, 우측 `›` 19px ink-2.
- 고객 문의: 업체 블록(로고 없음: 상호 22/700, 대표 `[대표자명]`, 전화 밑줄, 영업지역, "영업시간 내 2시간 안에 연락드립니다"). 이름·전화(필수 표찰) → 랙 종류 2열 격자 + "잘 모르겠어요" → 공간 크기 3칸(단위 m suffix) → [현장 사진 찍기] 60px + 썸네일 스트립 → 메모 → 동의 직각 체크 → 하단 64px [무료 견적 문의하기]. 완료 화면: 접수번호 명판, 시각, 예상 연락 시간, [바로 전화] 잉크, [카카오톡 상담] 외곽선.
- 고객 견적서: 상단 행 상호 22/700 | 견적번호 명판 | 날짜. 총액 T1 + "부가세 포함". 시공 요약 한 줄. 품목표(1.5px 외곽, 헤더 행 canvas 배경, 열 품목/수량/금액, 규격은 다음 행 전체 폭 17 ink-2). 포함/불포함 2열 표. 신뢰: "설치 하자 1년 무상 A/S", "전자세금계산서 발행" 2행 텍스트(아이콘 없음). 시공 사진: 1.5px 실선 빈 박스 1개 "[시공 사진 준비 중]". 사업자 정보 표(`[000-00-00000]`). 하단 고정 64px: [전화로 확인하기] 잉크 전폭. [카카오톡 문의]·[이미지 저장]은 상단 우측 48px 외곽선 2개.
- 문구: "아버지" 금지 → "내 폰으로". 이모지·말풍선 도움말 금지. 가짜 로고 금지.
