# AI 활용 제안 v2 — 3자 토론 결과 (2026-09-16)

참여: Claude(리드), codex, Gemini 3.8(agy). 2라운드 진행. 세 참여자가 같은 결론에 도달했고, 리드의 "단가 보간 제안"은 두 참여자의 반대(원자재·시공 변수 미반영 → 그럴듯한 오가격)로 철회.

## 1. 현재 AI 기능 판정
| 기능 | 점수(리드/codex/Gemini) | 결정 |
|---|---|---|
| 고객 문의 메모 분석(추천 랙·규격·수량·가격) | 3/4/4 | **축소**: 가격·수량 추천 제거, "전화 전 확인할 질문 3개 + 가능성 높은 랙 종류"만 |
| 현장 사진+치수 분석 | 4/3/2 | **축소**: 바닥·장애물·주의사항 "현장 체크리스트"로만. 수량·규격 추천 제거 |
| 추천 품목으로 견적 작성(자동 담기) | 1 | **즉시 제거** (종류만 맞는 첫 행을 담는 방식은 오견적 위험) |

## 2. 제안 (우선순위 순)

### ① 말로 담기 — 음성 한 문장 → 품목 (1~3단계 통합)
- 1단계 화면 마이크 버튼. "경량랙 독립 천이백 사백오십 천팔백 세 대" → 브라우저 내장 음성인식(Web Speech API) → **로컬 규칙 파서**(수사 변환표: 천이백→1200, 세 대→3; 종류·형태 사전; W/D/H 연속 숫자) → 단가표 **정확 매칭만** 담기.
- Gemini는 규칙 파서가 완전히 실패한 문장에만, 그리고 온라인일 때만 백그라운드로 호출(기본 비활성 가능). 현장 오프라인에서도 동작.
- 미언급 기본값: 형태 → 독립형, 수량 → 1대(둘 다 노란색 "확인 필요" 표시). 같은 문장의 후속 품목은 직전 형태 상속.
- **복창 카드**: 24px 큰 글씨 `경량랙 / 독립 / 1200×450×1800 / 3대`. 초록=정확 매칭, 노랑=기본값, 빨강=미매칭. 수정은 타이핑 없이 [독립↔연결] 토글, [−/+] 수량, [다시 말하기]. 불확실 필드가 남으면 담기 버튼 비활성.
- 정확 매칭 실패 시: 종류·형태가 같고 **폭·깊이·높이 중 한 축만 다른** 후보 최대 3개를 칩으로 제시. 두 축 이상 다르면 후보 없이 수동 선택으로.
- 난이도 M. 효과: 품목당 탭 10~20회 → 말 1회 + 확정 1탭, 1~2분 → 10~20초.
- 검증: 2주간 원문·해석·수정 내역을 기록해 정확도 측정 후 기본 활성화 결정.

### ② 발송 전 검사 (6단계 확인)
규칙 기반이며 AI는 설명문만 담당.
| 항목 | 판정 |
|---|---|
| 단가 0원·미입력 품목 | 차단 |
| 단가표와 정확히 매칭되지 않은 품목 | 차단 |
| 수량 0 이하·치수 누락 | 차단 |
| 할인이 할인 전 총액 초과 / 총액 음수 | 차단 |
| 마진 중복 적용 | 차단 |
| 고객 연락처 없음 | 저장은 허용, 카톡 발송 단계에서 차단 |
| 연결형만 있고 독립형 없음 | 경고 |
| 단일 품목 100대 초과 또는 평소의 10배 | 경고 |
| 총액이 해당 고객 과거 평균의 5배 초과 | 경고 |
| 같은 종류·형태·규격 중복 행 | 경고 + "합치기" 1탭 |
| 마진율 5% 미만 또는 45% 초과 | 경고 |
| 고객명 누락 | 경고 |
차단은 수정 전 진행 불가, 경고는 항목별 확인 체크 후 진행. 난이도 S~M.

### ③ 카톡 문구 자동 작성 (미리보기·완료 화면)
템플릿(3~4줄):
> 안녕하세요, {고객명}님. 요청하신 {품목 요약} 견적서를 보내드립니다.
> 총 견적금액은 {총액}(VAT 포함)이며, 견적 유효기간은 {유효기간}까지입니다.
> 규격·수량 확인 부탁드리고, 문의는 {연락처}로 주세요. 감사합니다.
- 고객명·품목·규격·수량·총액·할인·부가세·유효기간·연락처는 **템플릿 고정값**(AI 수정 금지). Gemini는 인사말 톤과 고객 메모를 반영한 안내 한 줄만 다듬음(예: "현장 엘리베이터 유무 확인 부탁드립니다").
- 자동 발송 없음. 복사 후 사장님이 카톡에서 보냄. 난이도 S.

### ④ (보조) 이전 견적·반복 규격 추천
고객 선택 시 유사 과거 견적 3개와 자주 쓴 규격 제시, "초안으로 복사"만 허용하고 단가는 현재 단가표로 재조회. 현재의 "최근 견적에서 시작"을 확장하는 수준. 난이도 M.

## 3. 하지 말 것 (세 참여자 합의)
- 사진만으로 치수·수량을 정해 자동 견적 생성.
- 단가 미입력 규격의 가격을 AI가 보간·제안.
- 고객에게 AI가 직접 답하거나 승인 없이 견적을 발송.

## 4. 하나만 먼저 만든다면
**① 말로 담기.** 60대 사장님의 가장 큰 마찰(작은 칩 찾기·타이핑)을 직접 없애고, 입력 범위가 종류·형태·치수·수량으로 좁아 검증이 쉽다. 규칙 파서 우선 설계라 Gemini 없이도 동작해 현장 오프라인에 강하다. 다만 리드는 ③(카톡 문구)이 가장 싸고 매일 쓰이므로 ①과 같은 주에 함께 넣기를 권한다.
