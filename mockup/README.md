# 용인랙 견적 앱 클릭 목업

백엔드 없이 동작하는 모바일 우선 HTML 목업입니다. index.html을 열면 390×844 직사각 폰 프레임으로 주요 화면을 비교하고, 각 프레임 안에서 직접 조작할 수 있습니다.

## 파일과 화면

| 파일 | 포함 화면 |
|---|---|
| index.html | 디자인 시스템 v2 전체 화면 갤러리 |
| app.html | 홈, 직접 고르기, 확인, 저장, 완료, 업무함, 견적 상세, 관리, 단가표 |
| customer-request.html | 공개 고객 문의, 입력 오류, 랙 선택, 사진 상태, 접수 완료 |
| customer-quote.html | 공개 고객 견적서, 품목표, 포함·불포함, A/S, 사업자 정보 |

app.html은 #home, #types, #review, #saving, #done, #inbox, #quoteDetail, #manage, #prices, #priceList 해시로 특정 상태를 바로 확인할 수 있습니다. 고객 문의 완료는 customer-request.html#done입니다.

## 대표 클릭 흐름

1. 홈에서 **직접 고르기**를 누릅니다.
2. 한 시트에서 랙 종류, 규격, 수량을 고른 뒤 **담기**를 누릅니다.
3. 고객, 품목, 부대비용, 마진, 할인을 확인합니다.
4. **저장하고 견적서 만들기**를 누르면 저장 중 상태를 거쳐 완료 화면으로 이동합니다.
5. 완료 화면에서 견적서를 공유하거나 하단 탭으로 업무함에 이동합니다.
6. 업무함에서 문의 전화, 견적 작성, 내 폰으로 주소 보내기, 최근 견적 상세를 확인합니다.
7. 관리에서 단가표와 규격별 단가 편집 시트를 확인합니다.

## 설계 결정 — 디자인 시스템 v2

- 시각 언어는 명판 표찰 한 종류, 1px 규칙선, 1.5px 블록 외곽선으로 제한했습니다. 기둥·빔 장식과 치수 인출선은 사용하지 않습니다.
- 모든 모서리는 0px이고 그림자는 없습니다. 색상 선언은 v2 토큰을 통해서만 사용합니다. 표면 흰색은 --surface 하나입니다.
- IBM Plex Sans KR 400/500/600/700을 Google Fonts로 불러오고, 폴백은 "Noto Sans KR", system-ui입니다. 글자는 17px 이상이며 굵기는 700을 넘지 않습니다.
- 숫자는 모두 tabular lining nums로 표시합니다. 제목 체계는 T1 34/700, T2 26/700, T3 21/600, T4 19/600, T5 18/500, T6 17/500을 따릅니다.
- 간격은 8/12/16/24/32/40px 토큰만 사용합니다. 오류 문구의 4px 간격은 calc(var(--s1)/2)로 표현합니다.
- 모든 조작은 최소 48px입니다. 일반 행동은 56px, 핵심 행동과 고정 하단 바는 64px, 홈 시작 버튼은 72px입니다.
- 입력 시트와 확인 화면에서는 탭바를 숨기고 단일 작업에 집중합니다. 탭바는 홈·업무함·관리·완료에서만 표시합니다.
- 선택 상태는 1.5px 잉크 외곽선과 우측 **선택됨** 표찰로 표시합니다. 비활성 행동은 전용 배경·글자 토큰을 쓰며 탭하면 3초 동안 이유를 안내합니다.
- 계산 순서는 품목 합 → 부대비용 합 → 마진율 적용 → 할인 차감 → 부가세 10% 반올림입니다. 할인은 마진 적용 후 금액을 넘을 수 없습니다.
- 앞 단계 변경 시 뒤 선택을 유지합니다. 랙 종류가 바뀌는 경우에만 규격을 초기화합니다.
- 전화번호는 전화 아이콘과 밑줄로 표시하고, 모든 행동은 외곽선 또는 면 버튼으로 제공합니다.
- 갤러리의 폰 프레임은 노치나 둥근 외형 없이 1.5px 잉크 테두리 직사각형으로 표현합니다.

## 범위와 후속 과제

실제 저장 API, 카카오톡 SDK, 전화 발신 결과, 사진 업로드, 이미지 생성은 연결하지 않았습니다. 해당 행동은 목업 안의 상태 변화와 안내로 확인할 수 있습니다.

**후속 과제:** 넓은 화면에서 품목과 계산 내역을 동시에 편집하는 데스크톱 적산 시트는 이번 모바일 v2 범위에서 제외했습니다.
